# MEMENTO

A small platformer about collecting the light.

The world went dark, and the memories scattered. You are the last light left.

## Play

Move: `←` `→` or `A` `D` · Jump: `Space` / `W` / `↑` · Double-jump in the air.

Collect every memory fragment to open the portal, then descend deeper.

## Run locally

Any static file server works:

```bash
python3 -m http.server 8080
```

then open http://localhost:8080

## Deploy

Static site served by nginx (see `Dockerfile`).
